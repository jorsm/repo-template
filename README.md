# repo-template
Template sperimentale per un flusso di lavoro con agenti Claude Code: spec, mappa del repo, PR come post-it, valutazione.

Stato: laboratorio. Nessun meccanismo è ancora costruito. Il punto di partenza, con fatti, decisioni e questioni aperte, è in [`docs/punto-di-partenza.md`](docs/punto-di-partenza.md).
